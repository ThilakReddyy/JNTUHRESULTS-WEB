<h2>機能</h2>

<ul>
  <li>特定学生の全学期の成績 – メッセージ欄に学籍番号を入力し、「Results」をクリックします。すべての学期の成績が表示されます。特定の学期の成績には、通常試験とすべての補習試験の結果が含まれます。</li>
  <li>特定学期の全学生の成績 – 学籍番号の範囲を指定し、学期を選択します。指定された範囲の学籍番号に対応する成績が表示されます。</li>
</ul>

<h2>開発モードでのローカル実行</h2>

<p>始めるには、まずリポジトリをクローンして <code>npm install && npm run dev</code> を実行してください：</p>

<pre>
git clone https://github.com/ThilakReddyy/JNTUHRESULTS-WEB.git
npm install
npm run dev
</pre>

<h2>本番環境でのビルドとデプロイ</h2>

<p>このサイトを本番環境で動かしたい場合は、まずモジュールをインストールし、<code>npm run build</code> を実行してサイトをビルドした後、<code>npm start</code> を実行して起動させる必要があります：</p>

<pre>
npm install
npm run build
npm start
</pre>

<p>サイトに変更を加えた際は、必ず再度 <code>npm run build</code> を実行してください。</p>

<p>結果を確認するには、ブラウザで<a href="http://localhost:3000">http://localhost:3000</a>を開いてください。</p>
