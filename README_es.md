<h2>Características</h2>

<ul>
  <li>Calificaciones de todos los semestres de un estudiante en particular: ingrese su número de registro en el campo de mensaje y haga clic en “Resultados”. Se mostrarán las calificaciones de todos los semestres. Los resultados de un semestre específico incluyen tanto los exámenes regulares como todos los exámenes complementarios.</li>
  <li>Calificaciones de todos los estudiantes de un semestre determinado: indique el rango específico de números de registro y seleccione el semestre. Se mostrarán los resultados correspondientes a ese rango de números de registro.</li>
</ul>

<h2>Ejecutar localmente en modo de desarrollo</h2>

<p>Para comenzar, basta con clonar el repositorio y ejecutar <code>npm install && npm run dev</code>:</p>

<pre>
git clone https://github.com/ThilakReddyy/JNTUHRESULTS-WEB.git
npm install
npm run dev
</pre>

<h2>Compilación e implementación en entorno de producción</h2>

<p>Si desea ejecutar este sitio en entorno de producción, debe instalar los módulos y luego compilar el sitio con <code>npm run build</code>, y ejecutarlo con <code>npm start</code>:</p>

<pre>
npm install
npm run build
npm start
</pre>

<p>Cada vez que realice cambios en el sitio, debe ejecutar nuevamente <code>npm run build</code>.</p>

Abra <a href="http://localhost:3000">http://localhost:3000</a> con su navegador para ver el resultado.
