<h2>功能特性</h2>

<ul>
  <li>特定学生的所有学期成绩——在输入框中填写您的学号，然后点击“成绩”按钮。系统将显示该学生的所有学期成绩，其中包含常规考试及所有补考的成绩。</li>
  <li>特定学期所有学生的成绩——输入相应的学号范围并选择学期，系统就会显示该范围内所有学生的成绩。</li>
</ul>

<h2>以开发模式在本地运行</h2>

<p>要开始使用，只需克隆该仓库并运行 <code>npm install && npm run dev</code> 即可：</p>

<pre>
git clone https://github.com/ThilakReddyy/JNTUHRESULTS-WEB.git
npm install
npm run dev
</pre>

<h2>在生产环境中进行构建与部署</h2>

<p>如果想要在正式环境中运行该网站，您需要先安装相关模块，然后使用 <code>npm run build</code> 构建网站，再通过 <code>npm start</code> 启动它：</p>

<pre>
npm install
npm run build
npm start
</pre>

<p>每当您对网站进行修改后，都应再次运行 <code>npm run build</code>。</p>

<p>使用浏览器打开<a href="http://localhost:3000">http://localhost:3000</a>即可查看结果。</p>
